# Blender Human Base Mesh component

The local `blender_human_head_cc0.blend` file contains the animation-ready
realistic head, sclerae, and irises extracted from Blender Foundation's
**Human Base Meshes v1.0.0** asset bundle.

- Source: https://download.blender.org/demo/bundles/bundles-3.6/human-base-meshes-bundle-v1.0.0.zip
- Publisher: Blender Foundation / Blender Studio
- License: CC0
- Download SHA-256: `46a912c0524072ac3b78c35d5d2471df7b8df102394a050ca8cd7184e3393648`
- Local changes: unrelated assets removed, multires modifier removed, transforms
  applied, and the retained meshes translated to the Frontier Guard coordinate
  system.

This authoring dependency is excluded from Godot export by `art/.gdignore`.
