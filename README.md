# AoE Simm

Visor web público del simulador de mesa desarrollado en Godot 4.

- [Abrir el visor Web](https://adportas.github.io/aoe-simm/)
- [Documentación del proyecto](godot/poc_tabletop_ar/README.md)

Cada cambio en `main` exporta automáticamente la vista Web mediante GitHub
Actions y la publica en GitHub Pages.
